# Servio

Cámara en alto + visión computacional para restaurantes: YOLO encuentra los platos de cada mesa, Claude estima cuánta comida queda, y el mozo recibe un aviso por Telegram cuando una mesa está por terminar, tiene platos vacíos o un plato sigue lleno mucho rato.

MVP de hackathon (24 h).
